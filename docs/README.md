# 文档索引

按「当前是否还有效」分区。**找东西先看 operations（怎么做）和 acceptance（验过什么），
历史决策与过程记录都在 archive（为什么当时那么定）。**

```
docs/
├── operations/    当前有效：怎么装、怎么跑、怎么排障  ← 日常看这里
├── acceptance/    当前有效：验过什么、结论是什么
├── architecture/  当前有效：方案与架构设计
└── archive/      历史记录：任务包、决策过程、对外交付  ← 追溯用，不代表当前口径
```

> **archive 里的内容不代表当前口径。** 例如 v7 时代的方案、千问办公为核心的设计，
> 已被 v9/v10 决策取代。要看当前方向，读根目录的 [README.md](../README.md) 与 [ROADMAP.md](../ROADMAP.md)。
