## 一、两处补齐了项目空洞（最有价值的发现）

### ✅ 四种缓冲的合成公式，v8 和包 B 都回避了，看板给了

| 缓冲 | 看板实现 | 回填到 |
|---|---|---|
| 现金缓冲 B | **已验证到账 + 现金余额 − 刚性支出** | 施工单 3.5（原为 ○ 未定义） |
| 时间缓冲 | `B ÷ (M/30)`，`Math.round(f.buffer/(f.M/30))` | 施工单 3.6，与我此前建议的式子一致 |
| 融资缓冲 | 未使用授信 + 备用额度 | 施工单 3.5b 新增 |
| 经营调整缓冲 | 可调整支出 × 行业权重 Wop × **1.45** | 施工单 3.5c 新增 |

两点必须跟进：
1. 看板里 `f.buffer` 仍是**硬编码输入**，公式只写在卡片说明文案里，没有真正参与计算 → 落千问表格时要按文案实现，不能照抄输入值。
2. **系数 1.45 来源不明**——v8 §5.1—5.4 只有 Wop 权重，没有 1.45。要么是可调整空间的经验放大系数（须补进阈值来源表并标出处），要么是看板作者自造，答辩不能引用。

### ✅ 两条动态阈值兜底规则，v8 完全没有

```
GUARD = 0.70   动态 K红 下限 = 静态 K红 × 0.70，取较大者生效
BAND  = 0.10   K黄 ≥ K红 + 0.10，保证黄红带不被压扁
```

作用：防止滚动分位数把红线算到极低，导致"异常被正常化"（淡季漏报的极端形态）。**建议回写 v8 §4.2 与施工单 4.3/4.4**，这是我此前拍板 A4（同月有效样本 ≥3 才启用动态）之外的第二道闸，两者互补：样本量管"能不能算"，数值下限管"算出来能不能用"。

## 三、可以立刻复用的资产（省掉两轮重敲）

- **`IND` 对象含四行业完整参数**：Ky / Kr / Ty / Tr / Wfin / Wop / arR / invR / crR / debt / appr —— 与 v8 §5.1—5.4 逐项一致。`templates/` 那四个 json 现在还是空的 `{}`，可直接由它生成，并顺手做成 `param_template` 的 seed 来源。
- **`DEADA` 权重表满足 Σv+Σu=1**：X3 产出 .31、X6 投入 .24、X1 产出 .19、X5 产出 .26，其余为 0（稀疏非零四项）→ 可作为 `da_coefficient` 表的初始版本，不必干等离线求解。
- 管理会计四项已具象：边际贡献率 42.6% 绿、盈亏平衡 618 万 vs 现状 812 万（安全边际 23.9% 绿）、作业成本分摊偏差 7.4% 黄、应收周转 57 vs 45 天 红 → 补掉施工单 3.9 的 ○。

## 五、定位问题（需要你认可的一句话）

看板内联实现了 Q/D/P，而按裁决一，Q/D 的权威实现应在**千问表格**、P 在 **MCP**。于是同一套判定现在有三处实现。建议明确看板的角色为**"表格公式的参考实现 + 只读展示层"**，并在页面注明"计算逻辑与千问表格同源"；否则三处各改一版，答辩演示的数与表格里的数会不一致——这是这个项目最容易翻车的口径漂移点。
