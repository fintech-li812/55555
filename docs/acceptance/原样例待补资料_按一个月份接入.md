# 原样例下一步需提供或确认的资料
程序已能取证和检查，不要求你设计规则或手写JSON。按一个企业、一个明确月份先接入；可先提交资料，由程序侧整理登记。演示资料必须标合成，真实资料另验。

1. 统计主体、期间和账户：先选一个月份，列清纳入哪些账户、哪些排除；账户可用稳定脱敏编号。
2. 同一范围的期初及独立期末余额：期初取上月末、期末取本月末的独立余额记录/对账单，保留日期、账户、币种、金额和来源位置；不能用流水累加算出的期末代替实际期末。
3. 实际收付：所选期间账户的完整收支明细或有依据的经营/投资/筹资清单，标日期、方向、金额、凭证号；额度、贷款余额和还款计划不等于本期实际现金。
4. 具体数据处置：D8原值1631300的单位依据；行12/15是否同一笔重复以及保留依据；筹资C4的-40是否错误、正确值或业务解释；银行411.39与应收累计571.38是否存在未列付款/不同截止日期等凭证。
5. 来源关系：银行与经营月表哪些属于同一变动，哪些是补充证据；内部转账提供双方关联。程序负责执行明确关系，不凭同金额自动去重。

当前表里的期末253万元只是静态字段，不足以证明账户全范围独立余额。缺资料时保持待核，不自动改正常。
