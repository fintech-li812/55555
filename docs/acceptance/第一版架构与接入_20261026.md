## 本期链路

千问Agent → 9个MCP工具 → 已登记固定输入工作簿 → Python Decimal现场计算 → 用户指示后MySQL留档 → 精确回查 → 千问解释。主目录本地辅助看板调用同一引擎，可检查金额、差异及保存回执；它不替代千问真实工具调用验收。

程序工具calculate_manufacturing_cashflow按source_id计算，不接受任意路径或Agent自填金额。read_cashflow_result也会重新读取当前默认输入并计算，已不再只返回静态快照。save_cashflow_result保存前再计算并做完整对象比对；余额差异阻止保存。同一request_id保持幂等，提交不明要用原编号查询。
