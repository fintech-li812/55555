## 第 1 节 · 规则实现

四份工作簿分别独立部署。本版唯一靶子依据为发包方本轮真实 xlsx 全量复扫结果，已取代原任务书的坐标与内容。本文据此修订公式设计，未自行打开四份原件或在千问执行；“命中”为已确认靶子的规则归属及预期，不冒充本轮公式运行通过记录。单位保持万元，所有公式均不换算为元。

数据首行为 3；公式模板预留到第 10000 行，这只是部署容量，不是实际末行。只在实际数据行填充；超出容量必须同步扩展全部相关范围。第 2 行原表头不变。新增辅助列在第 4 节逐一声明，不能覆盖既有列；部署前需确认预留位置为空。

先新增同文件的“闸结果快照”“数据闸参数”“日期校验”三个 Sheet。回填前，将现金流水 I、应收账款 J 的原值逐行复制并【仅粘贴值】到闸结果快照 A、B；不得用链接公式当快照。无完整快照时不得声称缺值和原整行比较已完成。清空结果的埋错测试须先观察独立审计结果，再取快照，最后回填。

### gate_unit_mismatch · 单位混用

1. **适用 Sheet 与列**：现金流水!D3:D10000；结果辅助列 J，基准辅助列 S。
2. **首选公式**：以下为首个数据行公式；日期条目已注明其对应日期块。

```excel
=IF(NOT(ISNUMBER('现金流水'!D3)),"",IF('现金流水'!D3=0,"",IF(OR(NOT(ISNUMBER('数据闸参数'!$B$3)),NOT(ISNUMBER('数据闸参数'!$B$4)),NOT(ISNUMBER(S3))),"待校验",IF(OR(S3<=0,'数据闸参数'!$B$3<=1,'数据闸参数'!$B$4<'数据闸参数'!$B$3),"待校验",IF(AND(ABS('现金流水'!D3)/S3>='数据闸参数'!$B$3,ABS('现金流水'!D3)/S3<='数据闸参数'!$B$4),"单位异常","")))))
```

3. **降级公式**：同首选；S3 先写第 4 节的其余值绝对值均值公式。完全不使用四个待测函数。
4. **命中后写入闸结果列的枚举值**：`单位异常`。
5. **验证方法**：X-MANU-05：制造现金流水!D8=1631300；发包方给出的列中位数为180.7、约9032倍；看J8，批准倍数参数且本公式实际比值落入区间后应为“单位异常”。本公式仍使用其余值绝对值均值S8，不能将中位数180.7或约9032倍冒充S8及本公式比值。
6. **未决点**：⚠ 约 10⁴ 倍没有给出容差；数据闸参数!B3、B4 分别保留放大倍数下界、上界，不填默认值；未批准时返回“待校验”。其他万元列是否也按同一规则执行未明确，不能擅自扩展。

### gate_duplicate_row · 整行重复

1. **适用 Sheet 与列**：现金流水!A3:H10000 加闸结果快照!A；应收账款!A3:I10000 加闸结果快照!B。
2. **首选公式**：以下为首个数据行公式；日期条目已注明其对应日期块。

```excel
=IF(COUNTIF('现金流水'!A3:H3,"<>")=0,"",IF(SUMPRODUCT(--('现金流水'!$A$3:A3='现金流水'!A3),--(ISNUMBER('现金流水'!$A$3:A3)=ISNUMBER('现金流水'!A3)),--(LEN('现金流水'!$A$3:A3)=LEN('现金流水'!A3)),--('现金流水'!$B$3:B3='现金流水'!B3),--(ISNUMBER('现金流水'!$B$3:B3)=ISNUMBER('现金流水'!B3)),--(LEN('现金流水'!$B$3:B3)=LEN('现金流水'!B3)),--('现金流水'!$C$3:C3='现金流水'!C3),--(ISNUMBER('现金流水'!$C$3:C3)=ISNUMBER('现金流水'!C3)),--(LEN('现金流水'!$C$3:C3)=LEN('现金流水'!C3)),--('现金流水'!$D$3:D3='现金流水'!D3),--(ISNUMBER('现金流水'!$D$3:D3)=ISNUMBER('现金流水'!D3)),--(LEN('现金流水'!$D$3:D3)=LEN('现金流水'!D3)),--('现金流水'!$E$3:E3='现金流水'!E3),--(ISNUMBER('现金流水'!$E$3:E3)=ISNUMBER('现金流水'!E3)),--(LEN('现金流水'!$E$3:E3)=LEN('现金流水'!E3)),--('现金流水'!$F$3:F3='现金流水'!F3),--(ISNUMBER('现金流水'!$F$3:F3)=ISNUMBER('现金流水'!F3)),--(LEN('现金流水'!$F$3:F3)=LEN('现金流水'!F3)),--('现金流水'!$G$3:G3='现金流水'!G3),--(ISNUMBER('现金流水'!$G$3:G3)=ISNUMBER('现金流水'!G3)),--(LEN('现金流水'!$G$3:G3)=LEN('现金流水'!G3)),--('现金流水'!$H$3:H3='现金流水'!H3),--(ISNUMBER('现金流水'!$H$3:H3)=ISNUMBER('现金流水'!H3)),--(LEN('现金流水'!$H$3:H3)=LEN('现金流水'!H3)),--('闸结果快照'!$A$3:A3='闸结果快照'!A3))>1,"重复剔除",""))
```

3. **降级公式**：同首选；现金写 M3，应收写 L3。SUMPRODUCT 逐列相等，并比较数值类型和 LEN，避免以金额或拼接字符串代替整行。
4. **命中后写入闸结果列的枚举值**：`重复剔除`。
5. **验证方法**：X-MANU-02：制造现金流水行12、行15全同，M15应为“重复剔除”、M12保留；对应2026-07，最终结果查看I15。
6. **未决点**：⚠ 此处比较所有原列的单元格值，包括快照中的原闸结果；不比较样式及公式源文本。若业务要求忽略原闸结果，需明确后修改。

### gate_scale_sanity · 规模合理性

1. **适用 Sheet 与列**：企业基本信息!A3:B10000；新增 D3 输出总体校验。
2. **首选公式**：以下为首个数据行公式；日期条目已注明其对应日期块。

```excel
=IF(OR(COUNTIF('企业基本信息'!$A$3:$A$10000,"上年度营业收入")<>1,COUNTIF('企业基本信息'!$A$3:$A$10000,"在职人数")+COUNTIF('企业基本信息'!$A$3:$A$10000,"在职人数（人）")<>1),"待校验",IF(OR(NOT(ISNUMBER(INDEX('企业基本信息'!$B$3:$B$10000,MATCH("上年度营业收入",'企业基本信息'!$A$3:$A$10000,0)))),NOT(ISNUMBER(INDEX('企业基本信息'!$B$3:$B$10000,MATCH(IF(COUNTIF('企业基本信息'!$A$3:$A$10000,"在职人数（人）")=1,"在职人数（人）","在职人数"),'企业基本信息'!$A$3:$A$10000,0))))),"待校验",IF(OR(INDEX('企业基本信息'!$B$3:$B$10000,MATCH("上年度营业收入",'企业基本信息'!$A$3:$A$10000,0))<0,INDEX('企业基本信息'!$B$3:$B$10000,MATCH(IF(COUNTIF('企业基本信息'!$A$3:$A$10000,"在职人数（人）")=1,"在职人数（人）","在职人数"),'企业基本信息'!$A$3:$A$10000,0))<1),"异常","正常")))
```

3. **降级公式**：同首选；全部按字段名INDEX/MATCH精确取值，不固定字段所在行。人数只识别本次及原任务明确给出的“在职人数（人）”“在职人数”；两种字段合计出现次数不为1时返回“待校验”，不擅自选其中一条。
4. **命中后写入闸结果列的枚举值**：`异常`。
5. **验证方法**：X-TEC-01：按字段名找到“在职人数（人）”=-6200，经“人数<1”分支使企业基本信息!D3显示“异常”；“上年度营业收入”为正数6200，不是异常来源。零售人数86不构成X-RET-01靶子。
6. **未决点**：⚠ 缺字段、重名字段、非数值的处理未明确；本实现返回“待校验”，不新增业务规则 ID。

### gate_month_gap · 月份连续性断档

1. **适用 Sheet 与列**：现金流水!A3:A10000；T 月序号、P 连续性辅助。
2. **首选公式**：以下为首个数据行公式；日期条目已注明其对应日期块。


## 第 2 节 · 闸结果列回填公式

### 现金流水!I3

优先级：原闸结果缺值 → 关键金额缺失 → 非法日期 → 整行重复 → 负数流入 → 单位异常 → 月份断档 → 日期格式 → 未能判定 → 正常。

理由：先保留入口链断裂和不能直接计算的事实，再剔除重复与识别业务异常；单值输出不删除各辅助列中的其他命中证据。

```excel
=IF(COUNTIF(A3:H3,"<>")=0,"",IF(Q3<>"",Q3,IF(O3<>"",O3,IF(K3="非法日期",K3,IF(M3<>"",M3,IF(N3<>"",N3,IF(J3="单位异常",J3,IF(P3="断档告警",P3,IF(L3<>"",L3,IF(OR(K3="待校验",J3="待校验",P3="待校验"),"待校验","正常"))))))))))
```

I3 向下填充实际数据行；Q 使用覆盖前快照，不引用 I；因此无循环。若原 I 是空，回填后 I 显示“补录必填”，表示本批次发现过结果缺值；不能将其当作原格从未缺失。修复批次重新取快照再重评，保留旧批次证据。

### 应收账款!J3

优先级：原闸结果缺值 → 非法日期 → 业务键重复 → 整行重复 → 未标冲销负数 → 超收 → 到账金额不符 → 日期格式 → 未能判定 → 正常。

理由：保留缺值和非法日期，重复记录先剔除，负数及超收先于对账提示，所有独立命中仍可从辅助列审计。

```excel
=IF(COUNTIF(A3:I3,"<>")=0,"",IF(R3<>"",R3,IF(N3="非法日期",N3,IF(K3<>"",K3,IF(L3<>"",L3,IF(M3<>"",M3,IF(Q3<>"",Q3,IF(P3="金额不符",P3,IF(O3<>"",O3,IF(OR(N3="待校验",P3="待校验"),"待校验","正常"))))))))))
```

该顺序是本文显式列出的组合策略，任务未指定冲突优先级，须发包方确认。单一结果无法同时显示多个枚举；第 3 节必须同时检查对应辅助列，不能把被更高优先级遮住的结果当作漏检。
