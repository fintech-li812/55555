# 下午讲座：关于"以千问办公为核心"的界限问题清单

日期：2026-10-27 中午。用途：带去讲座现场，向千问办公相关方问清界限；回来后据此审批方案。
性质：**提问清单 + 初步计划 + 通俗简介**。不涉及任何真实企业数据，不含密钥。

---

## 第 0 节：30 秒自我介绍（可以直接念给对方听）

> 我们在做一个制造业现金流的分析工作台。
>
> 简单说：企业拿八张 Excel 表给我们——银行流水、应收账款、借款、投资这些——系统把每一笔钱分门别类归到"做生意的钱""买设备的钱""借来还去的钱"三类里，各自加总，最后拿算出来的期末余额去跟银行给的期末余额对账，差一块钱都要查清楚。
>
> 这套算法我们已经用 Python 写好了，在自己电脑上跑通了，四个测试场景全部对得上，负例会自动拒绝存档。
>
> 现在想把它做成**一个网址、谁都能打开、我关机它也还在**的东西。我们明确希望它是**"千问办公的工作台"**，而不是"随便部署在哪个云服务器上的一个网站"。
>
> 所以我今天想问清楚的就一件事：**到底什么情况下，你们认为一个东西算"以千问办公为核心"？这条线画在哪？**

---

## 第 1 节：我们现在的理解（人话版）

我们目前自己下的定义是四条，也都做到了：

1. **场所**：整套东西跑在千问分配的一个 `.qwenwork.host` 网址里，没有第二个地址。
2. **钱在这儿算**：金额由网址背后的程序算出来，网页本身一个数都不参与。
3. **数据在这儿存**：用千问给网页配的数据库。
4. **生死在这儿**：删掉这个网页，整套系统和数据一起消失。

我们还实测了运行环境：Node v22、2 核 CPU、约 1 GB 内存、可以联网调外部接口、第三方代码包可以打包进去。

**卡住的地方是**：我们用测试发现，**那条"往外走"的路是通的**——理论上我们完全可以只把页面放在千问，把最值钱的计算搬到自己的服务器上，或者调外面的模型。
所以"以千问为核心"这件事，对我们来说已经**不是能力问题，而是定义问题**。这就是为什么我一定要来问这条线在哪。

## 第 2 节：界限问题清单（按优先级）

### ★ 现场必问的 6 个（回答不了其余 15 个都白搭）

**A1｜你们有没有官方的判定标准？**
「以千问办公为核心」这句话，平台侧有没有一个可以对照的定义？是靠"跑在 Pages 上"就算，还是要看用了多少平台能力（网页、数据库、任务、工作流、身份）？
> 我想要一个可以打分的尺子，而不是我们自己给自己打分。

**A2｜我用自己的 Key 去调外面的模型，还算不算？**
平台自己不提供模型调用能力（我们实测确认了）。那如果我在自己的程序里去接通义或者其他模型的 API——**大脑在外面，身体在千问里**——这种情况下，还算"以千问办公为核心"吗？

**A3｜把钱放到别的服务器上算，算不算？**
如果我们把最核心的金额计算放在自己的另一台服务器上，千问这边只负责展示页面——**用你们的话说，这个东西该叫什么？是"千问应用"，还是"套了个千问壳子的外部系统"？**
> 这是我们上一版方案被自己人否掉的原因，我需要权威的说法。

**A4｜反过来问：如果网页没什么逻辑，真正的编排在千问的"任务/工作流/智能体"里，网页只露一张脸——这种是不是反而更"核心"？**
> 我们拿不准"核心"到底该押在**网页**上，还是押在**千问的任务与智能体编排能力**上。可能我们从一开始就押错了地方。

**B1｜能不能注入自定义环境变量？**
我们实测运行时只有 9 个平台自己的变量。我能不能自定义一个，比如塞一把 API Key 进去，让服务端程序读到？
> 这一条直接决定我们的 AI 功能是生还是死。答"不能"，我们就干脆不做 AI。

**B3｜我们实测能往外网发 HTTPS 请求，这是被允许的正常用法吗？**
调到了 npm 的库和阿里云官网，都通。但不知道这是"支持的能力"还是"没人管的缝隙"。会不会有白名单、审计，或者以后被关掉？

### 有机会就问（15 个，分五组）

**B 组｜能做到哪一步**
- B2：`node_modules` 打包有没有体积上限、包数量上限？
- B4：能不能不挂内置数据库，而去连我自己的数据库？允许吗？
- B5：单个请求超时具体几秒？（这一条关系到能不能在一个请求里跑完"计算+保存"）

**C 组｜数据归属**
- C1：存在内置数据库里的数据，合规上算谁的？
- C2：能不能完整导出？什么格式？
- C3：将来想整个搬走，可行吗、要多久？

**D 组｜访客与身份**
- D1：陌生人打开公开网址，天然就是匿名身份吗？
- D2：**能不能用千问或钉钉的身份做登录、做租户隔离？**（这一条如果可以，我们最担心的"多用户隔离是玩具"就有救了）
- D3：个人空间和企业空间，能力差在哪？
- D4：免费档到底能不能建动态网页并挂数据库？最低要哪一档？

**E 组｜账单与退场**
- E1：单个网页每月访问量、流量的具体额度是多少？
- E2：冷启动大概多久？（我们碰到过页面要好几秒才起来）
- E3：要正式对外给客户用，有没有合规流程或报备要求？
- E4：**如果哪天我不续费了，我的代码和数据怎么取出来？**

**F 组｜生态位置**
- F1：网页、任务、工作流、技能、智能体、钉钉侧边栏——对一个要长期用的工作台来说，你们建议以哪个为主入口？
- F2：同一套东西能不能同时从网页和钉钉进去？
