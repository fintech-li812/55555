## 阶段 4 · 风控闸（判定核心，表格内完成）

| 序 | 函数 | 公式/逻辑 | 依据 |
|---|---|---|---|
| 4.1 | `静态阈值判定` | 缓冲 < M×K红 → 红；< M×K黄 → 黄；否则绿 | v8 §4.1、§5.1~5.4 K 系数 |
| 4.2 | `相对指标判定` | 应收/存货周转倍数 >1.3 关注、>1.5 黄；流动比率比 <0.7 黄、<0.5 红；资产负债率 >警戒线 红；利息保障 <1.0 红、<2.0 黄 | v8 §5.0 |
| 4.3 | `动态阈值 K黄/K红` | `K黄=PERCENTILE(同期缓冲倍数,0.25)`、`K红=0.10`；**满 12 个月才启用**，不足强制静态并回退提示 | v8 §4.2 |
| 4.4 | `混合模式` | 静态×0.7 + 动态×0.3 | v8 §4.2 |
| 4.5 | `判别得分 D` | `=SUMPRODUCT(v_投入,投入指标)+SUMPRODUCT(u_产出,产出指标)`，权重来自 1.x 的 `load_da_coefficients`；D<0 → 风险 | v8 2-A.5；**折中口径：表格内算** |
| 4.6 | `rf_predict(features)` | **唯一 MCP 计算工具**：30 维特征（15 指标+15 Benford 因子）→ sklearn 推理 P ∈[0,1]；写 rf_predict_log（含 model_version）；P 仅作修正因子 | 裁决一 |
| 4.7 | `FUSE(Q,D,P)` | 红：`(D<0 且 P≥0.7) 或 Q<0.3`；黄：`(D<0 且 0.3≤P<0.7) 或 (Q<0.5 且 D<0)`；绿：`D≥0 且 Q≥0.5` | v8 §2-A.7 |
| 4.8 | `复合规则` | 例：回款延期>30天 且 融资缓冲<M×K黄 → 红灯；○ 其余 9 条待包 A 出 |
| 4.9 | `归因贡献度` | 各因素占比 + DEA-DA 权重解读（哪些指标非零权重决定判定） | v8 §7.3 第二层 |
| 4.10 | `样本不足处置` | M=0 或无完整月份 → 标"不可判定"，**不得补零报绿** | 协议 §5.1 |
