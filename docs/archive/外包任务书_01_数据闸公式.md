## 一、背景（读完就够，不要展开追问）

我们在千问办公表格里做企业财务风险管控。数据进入计算前必须先过一道「数据闸」，用表格公式拦掉脏数据，并在每张表的最后一列写出拦截结论。你的任务就是**把这些公式写出来**，包括在关键函数不可用时的降级写法。

三层风控模型（Q/D/P）、动态阈值、压力测试**都不归你管**，不要碰。

## 三、必须实现的 14 条规则（词表已固定，不许增删改名）

| 规则 ID | 名称 | 判定意图 |
|---|---|---|
| `gate_unit_mismatch` | 单位混用 | 万元列里出现了元级数值（放大约 10⁴ 倍） |
| `gate_date_invalid` | 非法日期 | 如 `2026-13-05`（13 月不存在） |
| `gate_date_format` | 日期格式不统一 | 同列混用 `2026/1/31`、`26年2月28日` 等非标准写法 |
| `gate_duplicate_doc_no` | 业务键重复 | 单据编号重复 |
| `gate_duplicate_row` | 整行重复 | 所有列逐格相同的重复行 |
| `gate_negative_income` | 负数流入 | 流入金额为负，且流水类型为收入 |
| `gate_negative_amount` | 负数金额未标注冲销 | 应收金额为负，且备注里没有红字/冲销标记 |
| `gate_negative_credit` | 授信额度负数 | 筹资信息的额度为负 |
| `gate_missing_zero` | 关键金额缺失 | 经营性流出等关键金额单元格为空 |
| `gate_missing_result` | 闸结果列缺值 | 数据闸结果列本身为空（会切断下游判定链） |
| `gate_scale_sanity` | 规模合理性 | 上年度营业收入 < 0，或 在职人数 < 1 |
| `gate_month_gap` | 月份连续性断档 | 相邻两行的月份差 ≠ 1（如缺 2025-12） |
| `gate_payment_mismatch` | 到账金额不符 | 银行流水到账金额 ≠ 对应应收金额（按关联单据号匹配） |
| `gate_overpayment` | 超收 | 已收金额 > 应收金额 |

## 五、输出格式（严格按这 5 节，顺序不许变）

### 第 1 节 · 规则实现（14 条，每条一个三级标题）
每条必须给全 6 个字段：
1. **适用 Sheet 与列**（写清列字母与数据行区间，如 `现金流水!D3:D14`）
2. **首选公式**（单元格级，写成可直接粘贴的形式，如 `=IF(AND(D3<0,C3="收入"),"异常","")`）
3. **降级公式**（不使用 `FILTER`/`UNIQUE`/`PERCENTILE`/`SORT` 时的等价写法，必要时用辅助列，并说明辅助列放哪列、写什么公式）
4. **命中后写入闸结果列的枚举值**（只能从第六节的词表里取）
5. **验证方法**（一句话：拿第四节哪条埋错、看哪个单元格、应显示什么）
6. **未决点**（有则标 `⚠`，没有写"无"）

### 第 2 节 · 闸结果列回填公式
为 **现金流水!I 列**、**应收账款!J 列** 各给一条组合公式，按优先级串联全部适用规则，输出单一枚举值。要写明优先级顺序及一行理由。另给 **企业基本信息** 的校验单元格方案（该表是纵向键值结构，**必须用 INDEX/MATCH 按字段名取值，禁止硬编码行号**，因为四份文件行号不同）。

### 第 3 节 · 埋错对照表
17 行，列：`埋错编号 | 应命中规则 ID | 应显示的枚举值 | 对应公式所在单元格 | 自检说明`。

### 第 4 节 · 辅助列清单
若用了辅助列，逐条列出：Sheet、列、公式、用途、是否影响原有列（**禁止覆盖现有任何一列**）。

### 第 5 节 · 未决问题清单
只列问题，不要猜答案，不要给"建议默认值"。

## 六、闸结果枚举值（闭集，只能取这些）

`正常` / `异常` / `重复剔除` / `格式待统一` / `非法日期` / `单位异常` / `断档告警` / `金额不符` / `超收待核` / `待校验` / `补录必填`

## 七、硬约束（违反任一条即打回）

1. **金额单位一律按「万元」处理**，公式里**不得**出现 ×10000 之类的换算（入库时才转元，不是你的事）。
2. 不得发明新规则 ID，不得新增枚举值，不得改动第四节任何埋错的数值。
3. 允许使用的函数白名单：`IF AND OR NOT ISBLANK ISERROR ISNA ISNUMBER VLOOKUP INDEX MATCH COUNTIF COUNTIFS SUMIF SUMIFS LEN LEFT RIGHT MID VALUE TEXT YEAR MONTH DAY DATE DATEVALUE ABS ROUND IFERROR SUMPRODUCT`。
4. `FILTER`、`UNIQUE`、`PERCENTILE`、`SORT` **尚未在平台实测**：可以用，但**必须同时给降级公式**。
5. 非法日期检测必须用 `ISERROR(DATEVALUE(...))` 或等价手段，不能只比长度；`2026-13-05` 必须被判为非法而不是被自动进位成 2027-01-05。
6. 单位混用检测不得依赖硬编码阈值金额；应基于该列其余数据的量级比较（说明你用的倍数判据）。
7. 所有公式必须**单文件内自洽**，跨 Sheet 引用写完整 Sheet 名；不得依赖任何外部表。
8. **不得输出 Python、SQL、JSON、CSV**，只输出 Markdown 与表格公式。
9. 涉及三层模型、动态阈值、压力测试、审批路由的内容一律不写。
10. 不确定的地方标 `⚠` 并进第 5 节，**严禁靠猜测填空**。
