## 1. 五项裁定

### N1 自定义环境变量 —— **不支持（实测，确定性高）**

三重一手证据：
1. 发布器硬拦：`.env` 文件直接报错 `Dynamic runtime contains a sensitive file: .env`；
2. 运行时 `process.env` 全量 9 键，全部平台自用，无注入入口；
3. 三个 Pages 工具（publish / provision_database / apply_migration）的参数里都没有 env 键值对。

规避路径（改名 `config.txt` 混进包）技术可行但**违反技能契约明文红线**（"Do not include secrets"），不采用。

**对 AI 的直接影响**：让模型 Key 只待在服务端、不进浏览器——**原生走不通**。仅剩三条路：

| 路径 | 评价 |
|---|---|
| 前端持 Key 直连模型 | 共享 Key 场景等于泄露，**违反我方红线，排除** |
| 配置文件混包 | 违反官方红线，**排除** |
| **外部代理**（Key 放在外部服务，页面只调代理） | 技术最干净，**但引入了一个千问之外的组件** |

### N2 第三方依赖交付 —— **通（实测跑通）**

千问在对话内完成 `npm install decimal.js` → 打包 → publish → 服务端 `require` 成功，`Decimal('0.1').plus('0.2') = '0.3'`（301KB 单包，node_modules 随 runtime.zip 上传）。

要点：
- `package.json` 只是声明，运行时**不会**自动装；真正生效的是打包进去的 node_modules；
- 交付形态：**千问代装代发，用户无需手动 zip**；
- 我方核心算法仍是零第三方依赖，此路通只代表"需要时随时能用"。

### N3 网关超时 —— **30 秒硬上限（阶梯实测）**

29.5s 通过 / 30.0s 起 HTTP 524。响应头 `Server: ESA` + `X-Fc-Request-Id` 显示底层为阿里云函数计算（FC HTTP 触发器默认 30s，Page 侧固定）。

**对设计的影响**：我们的计算是秒级，"计算 + 保存"同请求完成没有压力（阈值留 1s 冗余即 29s）。架构不变。若未来有超长任务，拆两段：A 请求计算返回中间态 → B 请求落库。

### N4 套餐门槛 —— **免费可建动态页（实测）；挂库最低个人标准版（第三方口径，未实测）**

- 免费版建动态页：**实测确认**（本账号 tier=个人免费版，V1/V2 两次 publish 均成功）；
- 挂载数据库：第三方定价整理口径一致——免费 ❌ / 个人标准版 ✅（98 元/月，连续包月 78 元/月）——**这是推断不是实证**；
- 官方文档未直写"免费不能挂库"。

### N5 删网页与数据库 —— **确认永久回收（官方文档原文）**

《我的网页》："删除会真实释放数据库，无法找回"；被动暂停（配额打满/降级）则数据完整保留。
**设计后果：导出端点（如 `/api/export`）从"可选"升级为 Stage 3 必做项。**
