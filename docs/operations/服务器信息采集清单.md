# 服务器信息采集清单（局域网 2C2G 那台）

> 用途：把 `部署手册.md` §3/§4 从"待填命令"变成"可直接执行的定稿"。
> 用法：整段粘贴到服务器终端执行，输出会存成 `/tmp/cf-server-info.txt`，把内容贴回对话即可。
> 安全：**不要在对话里贴任何口令、密钥、token**。脚本本身不读取凭据文件。

---

## 1. 采集项与它阻塞的决策

| # | 项目 | 为什么要 | 影响哪一步 |
|---|---|---|---|
| 1 | OS 发行版与版本、架构 | v8 §8.2 用的是 `apt`。若是 CentOS/RHEL 要换 `dnf`，Windows Server 要整段重写 | §3.1 / §3.3 全部命令 |
| 2 | 内存与 swap 实测 | 我的预算约 1.1 GB / 2 GB。若网站应用已吃掉 800 MB，`rf_predict` 放服务器这条折中方案就得挪回笔记本 | §2 内存预算、裁决一 |
| 3 | 当前 RSS 前 8 进程 | 看"还有没有别的服务在跑"（宝塔/php/Java/Nginx worker） | 同上 |
| 4 | 磁盘剩余 | MySQL 数据 + 每日 mysqldump 保留 7 天 | §7 备份 |
| 5 | 内网 IP、网段 | 千问连接器要填 `http://<IP>/mcp`；要和笔记本同网段才通 | §4 |
| 6 | MySQL 是否已装、是否在跑、监听在哪、`bind-address` | 协议要求 MySQL 不对公网/局域网暴露，只绑 127.0.0.1 | §3.1 |
| 7 | Python 版本、pip、venv | `requirements.txt` 的写法与安装命令 | §3.3 |
| 8 | **能否访问 PyPI** | **最容易改架构的一条**：装不了 scikit-learn，P 值推理就不能放服务器，得回到 stdio 本地方案或预打包 wheel | 裁决一、施工单 4.6 |
| 9 | Nginx 是否已装、现有站点配置 | v8 §8.1 声称"已有 Nginx + HTTPS"。若没有，§3.4 反代要么现装、要么改成 uvicorn 直听内网 | §3.4 |
| 10 | 有没有域名 / 能不能签 Let's Encrypt | 内网地址签不了公网证书。没有 HTTPS 就要在答辩里按协议 §3.3 定性为"受限接入方案" | §5 偏差登记 |
| 11 | 防火墙是 ufw 还是 firewalld、SELinux/AppArmor | 反代常见坑：SELinux 开着会挡 Nginx 连 127.0.0.1:8000 | §3.4 |
| 12 | 时区与 NTP 同步 | 库内统一 UTC；服务器时区乱会让备份 cron 和 `occurred_at` 转换出错 | §3.3、§7 |
| 13 | 有没有 Docker | 有的话 MySQL+MCP 可容器化，比裸装更可复现、答辩换机演示更省事 | 部署形态选型 |
| 14 | sudo 权限情况 | 决定你自己执行还是授权我远程执行 | 执行方式 |

## 2. 一键采集（Linux / macOS 终端直接粘）

```bash
{
echo "===== 采集时间 ====="; date; (timedatectl 2>/dev/null | head -6) || cat /etc/timezone 2>/dev/null
echo; echo "===== 系统 ====="; uname -a; grep -E '^(NAME|VERSION|ID|VERSION_ID)=' /etc/os-release 2>/dev/null
echo; echo "===== CPU / 内存 ====="; echo "核数: $(nproc 2>/dev/null)"; free -h
echo "swap 设备:"; (swapon --show 2>/dev/null | grep .) || echo "  无 swap —— 需要配 2G"
echo; echo "===== 磁盘 ====="; df -h / /var 2>/dev/null
echo; echo "===== RSS 前 8 进程 ====="; ps -eo pid,comm,%mem,rss --sort=-rss 2>/dev/null | head -9
echo; echo "===== 网络 ====="; (hostname -I 2>/dev/null) || (ip -4 addr show scope global 2>/dev/null | grep -o 'inet [0-9.]*')
echo "默认网关:"; ip route 2>/dev/null | grep default
echo; echo "===== MySQL ====="; (command -v mysql >/dev/null && mysql --version) || echo "  未安装"
systemctl is-active mysql mysqld mariadb 2>/dev/null | paste -sd' ' || true
(ss -lntp 2>/dev/null | grep -E ':3306') || echo "  3306 未监听"
grep -R "^bind-address" /etc/mysql/ 2>/dev/null || echo "  未找到 bind-address 配置"
echo; echo "===== Python ====="; python3 --version 2>&1; pip3 --version 2>&1
python3 -c "import venv; print('venv: 可用')" 2>&1 | tail -1
echo; echo "===== 外网连通性（PyPI） ====="; timeout 12 curl -sS -o /dev/null -w "pypi.org HTTP %{http_code}  用时 %{time_total}s\n" https://pypi.org/simple/ 2>&1 || echo "  不可达 —— scikit-learn 需预打包或改本地推理"
echo; echo "===== Nginx / 网站 ====="; (command -v nginx >/dev/null && nginx -v 2>&1 && systemctl is-active nginx) || echo "  nginx 未安装或未运行"
ls -1 /etc/nginx/conf.d /etc/nginx/sites-enabled 2>/dev/null
grep -REh "^\s*(server_name|listen)" /etc/nginx/conf.d /etc/nginx/sites-enabled 2>/dev/null | head -10
echo; echo "===== 防火墙 / 安全模块 ====="
(command -v ufw >/dev/null && ufw status | head -4) || echo "  无 ufw"
(command -v firewall-cmd >/dev/null && firewall-cmd --state 2>&1) || echo "  无 firewalld"
echo "SELinux: $(getenforce 2>/dev/null || echo 无)"; echo "AppArmor: $(systemctl is-active apparmor 2>/dev/null || echo 无)"
echo; echo "===== Docker ====="; (command -v docker >/dev/null && docker --version 2>&1) || echo "  无 docker"
echo; echo "===== sudo ====="; (sudo -n true 2>/dev/null && echo "  免密 sudo 可用") || echo "  需要口令（不要把口令贴进对话）"
} 2>&1 | tee /tmp/cf-server-info.txt
```

## 3. 若服务器是 Windows Server，改跑这段（PowerShell 管理员）

```powershell
"===== 系统 ====="; systeminfo | Select-String "OS Name|OS Version|System Type|Time Zone"
"===== CPU/内存 ====="; (Get-CimInstance Win32_ComputerSystem).NumberOfLogicalProcessors
$os=Get-CimInstance Win32_OperatingSystem; "总内存GB: {0:N1}  可用GB: {1:N1}" -f ($os.TotalVisibleMemorySize/1MB), ($os.FreePhysicalMemory/1MB)
"===== 磁盘 ====="; Get-PSDrive -PSProvider FileSystem | Select Name,Used,Free
"===== 网络 ====="; Get-NetIPAddress -AddressFamily IPv4 | Where {$_.PrefixOrigin -ne 'Loopback'} | Select InterfaceAlias,IPAddress
"===== MySQL ====="; Get-Service *mysql*,*mariadb* -ErrorAction SilentlyContinue | Select Name,Status
Get-Command mysql -ErrorAction SilentlyContinue | Select Source
"===== Python ====="; python --version 2>&1; pip --version 2>&1
"===== 外网 ====="; try{(Invoke-WebRequest https://pypi.org/simple/ -UseBasicParsing -TimeoutSec 12).StatusCode}catch{"PyPI 不可达"}
"===== 监听端口 ====="; Get-NetTCPConnection -State Listen | Where {$_.LocalPort -in 80,443,3306,8000} | Select LocalAddress,LocalPort,OwningProcess
"===== 占内存前 8 ====="; Get-Process | Sort WS -Desc | Select -First 8 Name,@{n='RSS_MB';e={[int]($_.WS/1MB)}}
```

## 4. 还有三样不用命令，直接文字告诉我就行

1. **笔记本和服务器在同一个局域网吗**？能否 `ping <服务器IP>` 通、SSH/RDP 能连上。（决定 §4 的 URL 写内网 IP 还是得走路由）
2. **这台机器平时常开吗**？断电后会不会自动起来（`systemctl enable` + BIOS 来电自启）。它只影响"留痕可写"，不影响千问定时任务——那个跑在笔记本上。
3. **要不要授权我远程执行**？如果同意，配一个**密钥登录**（不要用口令），我从这台笔记本直接连上去跑 §3 并逐项验证。不方便给就你自己执行，把输出贴回来即可。

## 5. 拿到这些之后会改哪几份文档

| 采集结果 | 触发改动 |
|---|---|
| 非 Debian 系 / Windows | `部署手册` §3 全部命令重写 |
| PyPI 不可达 或 可用内存 < 900 MB | 施工单 4.6 的 `rf_predict` 从服务器挪到本地（改 stdio 方案），`requirements.txt` 拆分 |
| 无 Nginx 或无域名 | §3.4 删除反代、改 uvicorn 内网直听 + 防火墙白名单；§5 偏差登记加"仅 HTTP 内网" |
| 已有 Docker | §3 改写成 compose 版（推荐，答辩换机可复现） |
| SELinux=Enforcing | §3.4 追加 `setsebool -P httpd_can_network_connect 1` |
