### 4.3 `gate_` 规则全表（14 条，闭集）

规则**全文与可粘贴公式**在 `docs\外包交付\数据闸公式实现_v2.md` 第 1 节（逐条含首选公式、降级公式、验证方法、未决点）。此处给口径索引；`闸结果允许取值` = `正常 / 异常 / 重复剔除 / 格式待统一 / 非法日期 / 单位异常 / 断档告警 / 金额不符 / 超收待核 / 待校验 / 补录必填`（闭集，新增即打回）。

| 规则 ID | 判定（全部前置条件） | 闸结果 | 输出位置 |
|---|---|---|---|
| `gate_unit_mismatch` | D 列为数值、非 0，且 `\|D\|÷同列其余非零值绝对值均值` 落在已批准的倍数上下界内（上下界未批 → 返回待校验） | 单位异常 | 现金流水 J（辅助）→ I |
| `gate_date_invalid` | 显式年月日经 `DATE()` 构造回验 YEAR/MONTH/DAY 不一致，或文本 `ISERROR(DATEVALUE())` | 非法日期 | 日期校验!H → 现金 K / 应收 N → I/J |
| `gate_date_format` | 可解析文本但非 `yyyy-mm-dd`（不比较数值单元格显示格式，函数不可观测） | 格式待统一 | 日期校验!I → 现金 L / 应收 O |
| `gate_duplicate_doc_no` | 单据编号非空且自上而下 `COUNTIF` 前缀出现 >1（保留首条） | 重复剔除 | 应收 K → J |
| `gate_duplicate_row` | 同行区间非空且逐列值+数值类型+LEN 全等且快照闸结果亦等（>1 条） | 重复剔除 | 现金 M / 应收 L |
| `gate_negative_income` | **D 列为数值且 <0（已裁决不再要求 C 列="收入"，实测 C 值域为"经营性"）** | 异常 | 现金 N → I |
| `gate_negative_amount` | E<0 且备注不含"红字"且不含"冲销" | 异常 | 应收 M → J |
| `gate_negative_credit` | C 为数值且 <0 且 A 含"授信"或"额度"（无登记表机制） | 异常（其他负数→待校验） | 筹资 F |
| `gate_missing_zero` | 关键金额单元格为空或空串（只拦截，不补 0） | 补录必填 | 现金 O → I |
| `gate_missing_result` | I/J 原值为空——**必须先"仅粘贴值"取快照再回填**，否则证据被自身公式覆盖 | 补录必填 | 快照 C/D、现金 Q、应收 R |
| `gate_scale_sanity` | 按字段名 INDEX/MATCH 取"上年度营业收入"<0 或 在职人数（含"（人）"变体，两者合计须恰为 1）<1 | 异常 | 企业基本信息 D3 |
| `gate_month_gap` | 月序号 `年×12+月`，**与下一行**差 ≠1（告警标在前一行，即 2025-11 所在行） | 断档告警 | 现金 P → I |
| `gate_payment_mismatch` | 关联单据号在应收中唯一命中、双方均为数值、到账 ≠ 应收（无容差，不 ROUND） | 金额不符 | 银行 G → 应收 P → J |
| `gate_overpayment` | 应收、已收均为数值且 已收 > 应收 | 超收待核 | 应收 Q → J |

组合回填优先级（**已定稿**）：缺值 → 关键金额缺失 → 非法日期 → 重复 → 负数 → 单位异常 → 断档 → 日期格式 → 待校验 → 正常。
