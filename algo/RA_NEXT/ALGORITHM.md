# RA_NEXT 算法说明（ra-next-0.3）

候选目录：algo/RA_NEXT。只供离线算法研究；参考实现依赖仓库v8模块，未接入服务。历史v0.1/v0.2文件保存在history/；本版实测结论和验收边界以ITERATION_03.md为准。

## 一、Q：数字分布检验

统计量T=Σ(O−np)²/(np)。固定多项分布模拟B次，p=(1+ΣI(T模拟≥T观测))/(B+1)，避免零p值。30项检验用Holm逐步拒绝：排序p(i)，若p(i)≤alpha/(30−i+1)则拒绝，首次不满足即停止；Q=1−拒绝数/30。支持相关检验的族错误控制以单项p值有效和适用性成立为前提。

每个单项返回MC Wilson区间：中心=(h/B+z²/(2B))/(1+z²/B)，半宽=z sqrt((h/B)(1−h/B)/B+z²/(4B²))/(1+z²/B)，z=1.959963984540054。该区间描述模拟计数不确定性，不是企业真实性区间，30个区间也未作同时覆盖校正。没有把15个相关比率当30个独立伯努利试验估Q置信区间。

Benford概率p(d)=log10(1+1/d)；末位均匀概率0.1。首位/末位数字仍沿用基线定义，末位依赖六位格式去尾零；对限定区间财务比率的Benford适用性尚未证明。assess_reference默认不声明适用性，Q仅展示而作为不可用输入进入融合。

## 二、D：LP最优性证书与稳定性

保留基线标准化、逆指标、八指标与目标函数。max cᵀx, Ax=b, x≥0的对偶为min bᵀy, Aᵀy≥c，y自由。原始可行、对偶可行且目标相等时，由弱对偶性得到最优性。

certified_lp.py是纯标准库两阶段Bland单纯形：第一阶段人工变量，第二阶段原目标；冗余行移除、奇异基/迭代上限/无界或不可行显式返回失败。构造Bᵀy=c_B并核验原始/对偶残差和目标差，容差1e-7。只把通过数值证书的结果标记optimality_verified，不是精确有理数证明。

reference保留通过证书的基线解以避免多重最优权重导致D漂移；基线未通过时采用已认证候选解，仍失败则D=None且降级。CORE7保持历史未采用候选，未改动八指标配对。30次分层bootstrap给D和权重的经验分位区间，仅为探索稳定性；不保证95%覆盖。

## 三、P：固定特征、随机子空间与校准

原15比率加固定首位数字自信息−log(p(d))，替代训练池风险数字，避免用校准/测试行拟合风险数字。60棵深度4树、普通bootstrap、每树抽5/30特征；是按树随机子空间，不是按节点随机森林。类别不重新平衡，保留自然频率；合成训练组原本为1:1。

每类四分之一（至少3）从训练中留出校准，测试完全独立。拟合 sigmoid(a logit(p)+b)，a≥0保持单调；最小化平均二元交叉熵+0.1(a²+b²)/2。p裁剪至[.0001,.9999]。固定1000步、步长.05。投影梯度无穷范数≤1e-5才算优化收敛。校准集≥30且收敛时calibration_reliable=True，这只是候选工程/研究门槛，不证明概率已在真实业务校准。

P仍是可计算的校准数值；available表示产出数值，calibration_reliable表示策略条件。二者不可混用。树数0/样本不足/非法输入时P=None。仅10例校准不能作为可靠融合证据。OOB Brier针对森林未校准分数，不得误称独立校准性能；独立测试Brier=mean((p−y)²)，ECE按10等宽箱加权绝对偏差，分箱原始数据保留。

## 四、动态阈值（新政策候选）

输入带month及ratio的月序列与as_of；不支持拿无月份列表证明连续性。要求最近window个月完整连续且结束于评估月上月；遇非法/重复/未来记录不静默丢行。原始K黄=P25，K红=P10，线性插值；最终K黄=max(静态黄,P25)，K红=max(静态红,P10)，避免持续低缓冲让阈值随企业恶化下降。若原始分位相等则回退静态，原因明确。

3个月循环块bootstrap给探索分位数区间，未保证覆盖率，未输出虚构的“启用成功概率”。区间针对原始分位数，不是最终取静态下限后的决策阈值。此政策与线上动态阈值不是同一实施版本，需业务接受后再由工程侧接线。

## 五、多引擎统一视图（新政策候选）

截面FUSE/缓冲/13周时序先各自判级；时间缺口概率≥.30红、≥.10黄，否则绿，且必须temporal_validated=True。统一等级取已知维度最大严格度；缺一维时不能绿灯，全缺失为待复核。M×K与缺口概率不数值换算、不平均。此方法是等级决策规则，没有联合概率解释，不改原48格映射。

assess_reference显式传P可靠性；Benford适用性不明时Q不可用。影响：声明Q适用但只有10例校准时，固定三个场景灯色为黄/黄/黄。risk红转黄来自P证据失效，不是风险下降；默认Q未声明则按既定R1红灯。详见第三轮报告逐场景表。

## 六、参数、取值域与敏感性

|参数|默认值/范围|含义及敏感性|
|---|---|---|
|alpha|.05，(0,1)|增大更容易拒绝数字分布，Q倾向降低|
|simulations|1999，整数≥99|增加提升p值分辨率，冷启动线性增加|
|null seed|20261029|固定MC序列；换seed会有模拟误差变化|
|可用数字数|8|工程下限，非统计充分性证明|
|数值幅度上限|1e100|D/P拒绝更极端输入，避免标准化溢出|
|应收周转率|>0|拒绝缺失/非正而非自动填999天|
|LP residual tolerance|1e-7|收紧可能增加数值拒绝，放宽降低认证精度|
|LP pivot tolerance|1e-9|影响退化约束和入/出基选择|
|LP max_iter|10000/阶段，正整数|增加允许更多pivot，增加极端耗时|
|D bootstrap repeats|30，建议正整数|增加改善经验分位稳定性，线性增加求解成本|
|D bootstrap seed|20261029|固定分层重采样|
|n_trees|60，正整数|增加降低森林抽样噪声，线性增加成本|
|max_depth|4，固定|加深可提高训练拟合，也增加过拟合|
|subspace|5/30，固定|减小加强树间多样性，也可能遗漏信号|
|RF seed|20261027|控制划分、bootstrap和特征抽样|
|每类最小样本|8|仅保证可划分；不能证明足够校准|
|calibration fraction|每类1/4，至少3|增加减少森林训练集、增加校准样本|
|sigmoid clipping|1e-4|避免logit无穷；改变极端分数处理|
|sigmoid ridge|.1，固定正值|增加收缩极端概率，减少方差也可能欠拟合|
|sigmoid steps/lr|1000/.05|影响梯度残差和成本，不以测试集挑选|
|gradient tolerance|1e-5|收紧使可靠性更难通过|
|min calibration n|30，策略值|增加使可用证据更保守，不保证充分性|
|window|12，整数≥12|增加使用更长历史，可能稀释近期变化|
|P25/P10|.25/.10，固定|与黄/红经验分位对应，非已核实行业标准|
|threshold bootstrap|199，整数≥99|增加区间稳定性并增加成本|
|block length|3，固定月数|假设短期相关结构，未数据驱动选择|
|时间概率黄/红线|.10/.30，0≤黄<红≤1|降低阈值更易预警；沿用研究基线|
|Benford适用性声明|False|仅确认适用后显式True，不能据Q高自行确认|
|时间引擎验证声明|False|缺验证时不拿低概率支持绿灯|

可通过函数参数指定的值以reference.py/decision_policy.py签名为准；表中“固定”参数是实现常量，不宣称都有运行时配置接口。

## 七、实测、限制与出处

详见ITERATION_03.md和相应JSON证据：42候选测试双平台通过、33既有融合回归通过、30随机LP对照、实际DEA目标与HiGHS相符、10次跨平台数值摘要一致、冷热性能、校准比例变化600例合成评测。没有真实企业准确率；未测任务书指定Python3.13/3.12组合，不宣称任意平台逐位一致。源文件依赖SHA256在verification_v03.json。

方法依据：[SciPy linprog](https://cache-docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)、[scikit-learn calibration](https://scikit-learn.org/stable/modules/calibration.html)。LP证书由弱对偶性直接推导；动态阈值与统一视图为本项目候选设计。完整工程验收、业务批准与真实数据有效性仍未完成。
